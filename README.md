# Sample portal new instance via XML

Compatible with iTop 2.5+ (not sure about 2.4)

Note: This sample is package as a regular module in order to be used anywhere, but its real purpose is to show how you can use XML to create a new portal. Simply copy content from datamodel.xxx.xml to a production.delta.xml or into the ITSM Designer.
